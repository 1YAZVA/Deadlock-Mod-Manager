* Статусы кнопок карточки: **«Установить»** (золотой градиент), «Установлен»

  процесс игры, API, зеркало, чекбоксы поведения, тайминг Vanilla,
  кнопки Сохранить / Проверить API / Открыть папку данных.

## Логотип

Фирменная эмблема — «глаз в прицеле»: кольцо-прицел с перекрестием и
стилизованным глазом, состаренный бирюзово-ментовый металл на прозрачном
фоне. Оба фирменных акцента — в одной композиции.

* `assets/icon.png` (256×256, прозрачный фон) — иконка окна и трея;
* `assets/icon.ico` (16–256 px) — иконка `.exe` и ярлыков;
* `assets/logo.png` (256×256) — шапка приложения (44×44 в сайдбаре).

Эмблема встроена в репозиторий в base64 (`tools/logo_data.py`), иконки
собираются командой `python tools/make_icons.py` — одинаково локально и на CI.
Свой логотип можно подставить аргументом:
`python tools/make_icons.py путь/к/логотипу.png` — иконки пересоберутся.

## Типографика и метрика

* Шрифты — как на сайте: `Golos Text` 10 pt (текст) и `Unbounded`
  (логотип, заголовки). Оба встроены в приложение (base64,
  `dlmm/fonts_data.py`, лицензия SIL OFL 1.1); при недоступности —
  системный `Segoe UI`.
* Сайдбар: 250 px; навигация — кнопки-«чипы» 8 px скругления, активная —
  золотой текст на полупрозрачном золоте `rgba(200,169,106,0.14)`.
* Сетка каталога: карточки 236×324 px, шаг 14 px; число колонок
  пересчитывается при изменении ширины окна.
* Скругления: карточки 12 px, кнопки и поля 8–10 px (на сайте базовый
  `--radius: 0.75rem` = 12 px).

## Состояния и обратная связь

| Ситуация | Реакция интерфейса |
| --- | --- |
| Загрузка каталога | кнопки «Обновить»/«Загрузить ещё» блокируются, подпись «Загрузка…» |
| Ошибка сети | красная строка над счётчиком, текст ошибки GameBanana |
| Скачивание | модальный диалог: прогресс-бар (золотой градиент), «12.4 из 34.0 МБ · 5.2 МБ/с», «Отмена» |
| Установка завершена | информационное окно с именем файла и папкой |
| Vanilla-запуск | уведомление в трее «Моды временно перенесены…», затем «Моды возвращены» |
| Закрытие окна | сворачивание в трей + один раз подсказка «приложение в трее» |
| Игра заняла файлы | «Файл занят — закройте игру» (без traceback) |

## Трей

Иконка — логотип на прозрачном фоне; тултип «Deadlock Mod Manager».
Контекстное меню:

```
Вернуть моды (после Vanilla)      ← активно только когда Vanilla-бэкап существует
──────────────────────────────
Открыть Deadlock Mod Manager
Запустить Deadlock (с модами)
Запустить Deadlock (Vanilla)
──────────────────────────────
Выход
```

Одинарный/двойной клик по иконке — открыть окно. Всплывающие уведомления —
о сворачивании, Vanilla-сессии и возврате модов.
